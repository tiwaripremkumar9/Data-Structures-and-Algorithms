# DSA Interview Roadmap — Pattern-First (Arrays → Graphs)

*Goal: cover the patterns that actually repeat across SDE interviews — not every possible problem type. Skip low-frequency/niche patterns unless your target company is known for them.*

## 1. Arrays
- Two Pointers (sorted array problems)
- Sliding Window (fixed + variable size)
- Prefix Sum / Difference Array
- Kadane's Algorithm (max subarray)
- Cyclic Sort (missing/duplicate number)
- Dutch National Flag (3-way partition)

## 2. Strings
- Two Pointers (palindrome checks)
- Sliding Window (substring problems)
- Hashing (anagrams, frequency count)
- String Reversal / Rotation tricks

## 3. Hashing
- Frequency Map
- Complement Search (Two Sum pattern)
- Grouping by Key (group anagrams)
- Prefix Sum + HashMap (subarray sum = k)

## 4. Two Pointers (advanced)
- Opposite-direction pointers (container with most water, trapping rain water)
- Fast & Slow Pointers (cycle detection)
- Merge two sorted arrays

## 5. Sliding Window
- Fixed-size window
- Variable-size window (expand/shrink)
- Longest/shortest substring with a constraint

## 6. Binary Search
- Standard binary search
- Binary Search on Answer (search space reduction)
- Search in Rotated Sorted Array
- First/Last Occurrence variants

## 7. Recursion & Backtracking
- Subsets / Combinations
- Permutations
- Constraint satisfaction (N-Queens style)
- Backtracking with pruning

## 8. Linked List
- Fast & Slow Pointers (cycle detection, middle node)
- In-place Reversal (full + in groups of k)
- Merge Two Lists / Merge K Lists (via heap)
- Dummy Node technique

## 9. Stack & Queue
- Monotonic Stack (next greater/smaller element)
- Parenthesis Matching / Valid expressions
- Sliding Window Maximum (Deque)
- Min Stack design

## 10. Trees (Binary Tree + BST)
- DFS traversals (preorder/inorder/postorder)
- BFS / Level Order Traversal
- Recursive tree construction from traversals
- BST insert/search/validate
- Lowest Common Ancestor
- Diameter / Height / Balanced-check problems

## 11. Heap / Priority Queue
- Top-K elements
- K-way Merge
- Two Heaps (running median)

## 12. Trie
- Prefix search / Autocomplete
- Word search in a dictionary

## 13. Greedy
- Merge Intervals
- Activity Selection / Interval Scheduling
- Jump Game (reachability)

## 14. Dynamic Programming
- 0/1 Knapsack
- Unbounded Knapsack
- Longest Common Subsequence (family)
- Longest Increasing Subsequence
- Grid/Matrix DP (unique paths, min path sum)
- DP on Strings (edit distance, palindromic substrings)
- State Machine DP (buy/sell stock)

## 15. Graphs
- BFS / DFS traversal
- Topological Sort (Kahn's + DFS-based)
- Union-Find (Disjoint Set)
- Shortest Path (Dijkstra, Bellman-Ford)
- Minimum Spanning Tree (Prim's, Kruskal's)
- Cycle Detection (directed + undirected)
